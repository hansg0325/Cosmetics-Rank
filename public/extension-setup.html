최초 1회 브라우저 연결

설정 후 앱의 지금 수집하고 저장 버튼만 누르면 됩니다. 북마크나 JSON 파일을 옮길 필요가 없습니다.

  1. 평소 올리브영이 정상 표시되는 브라우저에서 확장 프로그램 관리 화면을 엽니다. 웨일: whale://extensions, Chrome: chrome://extensions, Edge: edge://extensions
  2. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드를 선택합니다.
  3. 아래 폴더를 선택합니다.
    C:\Users\admin\Documents\ChatGPT\Cosmetics Rank\extension
  4. 같은 브라우저에서 로컬 OliveRank에 접속해 로그인하고 새로고침합니다.
  5. 지금 수집하고 저장을 누릅니다. 새 랭킹 탭이 잠시 열리고, 정상 수집되면 닫히며 앱에 100행 저장 완료가 표시됩니다.

사용 권한

올리브영 사이트 화면을 읽는 권한과 로컬 OliveRank 버튼 연결만 사용합니다. 로그인 쿠키·비밀번호·브라우저 전체 방문 기록을 읽거나 저장하지 않습니다. 수집 결과는 로컬 앱에 전달합니다.

가격·이미지 제외 / 클릭 시에만 실행 / 예약 실행 없음. 접속 확인이나 차단으로 상품이 표시되지 않으면 해당 탭을 보여주고 중단합니다. 차단을 해결하거나 우회하지 않습니다.

현재 로컬 주소의 8787 포트만 지원합니다. Codex 내장 브라우저와 모바일은 이 확장 프로그램을 지원하지 않습니다. 실제 웨일·Chrome·Edge의 설치 및 권한 설정은 사용자 브라우저에서 완료해야 합니다.

코드가 바뀌면 확장 관리 화면에서 확장 프로그램을 새로고침하고 앱도 새로고침하세요.
