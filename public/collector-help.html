버튼으로 카테고리별 랭킹 수집

  1. 실행 중인 이전 서버가 있다면 터미널에서 Ctrl+C로 종료합니다.
  2. 프로젝트 폴더에서 bash ./start-local.sh를 실행합니다. 최초 한 번 Selenium 실행 환경을 자동으로 준비합니다. Chrome과 Python이 필요합니다.
  3. 앱에서 수집 카테고리를 선택하고 지금 수집하고 저장을 누르면 Chrome이 화면 없이 실행되고 해당 카테고리 1~100위를 검증한 뒤 저장합니다. 확장 프로그램이나 JSON 파일 업로드는 필요 없습니다.

전체 카테고리 취합을 누르면 전체·스킨케어·마스크팩·클렌징·선케어·메이크업·더모 코스메틱·헤어케어·바디케어·맨즈에딧을 순서대로 저장합니다. 완료할 때까지 앱 화면을 열어두세요. 실패한 카테고리는 따로 표시합니다.

순위·상품 ID·브랜드·상품명·원본 링크·수집 시각을 기록합니다. 가격과 이미지는 수집하지 않습니다. 같은 날 순위가 바뀌면 이전 버전을 보존한 새 버전으로 저장합니다. 같은 내용은 중복 저장하지 않습니다.

접속 확인이나 페이지 변경으로 100개를 읽지 못하면 실패로 표시하고 기존 완료 기록을 유지합니다. 수집은 버튼을 눌렀을 때만 실행하며 예약 수집은 하지 않습니다.

현재 이 기능은 로컬 PC 실행용입니다. PC가 꺼져 있거나 원격 배포 주소에서는 Chrome 수집을 실행할 수 없습니다.
