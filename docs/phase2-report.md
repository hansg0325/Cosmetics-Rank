## 동작

- 비교 기준은 같은 카테고리의 직전 성공 수집일입니다. 활성 COMPLETE 스냅샷만 사용합니다. 첫 기록에는 비교 없음, 중간 미수집일에는 간격 안내를 표시합니다.
- 상승·하락·동일·신규·이탈을 구분합니다. 미수집일과 100위권 밖은 서로 다른 상태로 보존하며 그래프 선은 끊습니다.
- 상품 이력 요약은 해당 카테고리의 전체 활성 기록에서 최초 진입일·최고 순위·마지막 기록을 계산합니다.
- 그래프는 최대 20개 상품, 조회당 최대 180일입니다. 1위가 위쪽이며 자동 축 또는 전체 1~100위 축을 선택합니다.
- 선이나 범례에 마우스를 올리면 해당 상품은 불투명도 1, 나머지는 0.14로 표시합니다. 날짜·상품·순위를 보여줍니다. 범례 클릭/터치로 강조를 고정하고 키보드 좌우 키로 날짜를 탐색합니다. 날짜별 데이터 표도 제공합니다.
- 비교 쿼리는 현재·이전 최대 200개 상품, 상품 검색은 페이지당 최대 100개, 이력은 180일로 제한합니다. 차트 이력 요청은 3개씩 실행합니다. D1 읽기/쓰기 사용량을 로그에 남깁니다. 원격 Workers CPU와 대규모 누적 이력 비용은 아직 측정하지 않았습니다.
