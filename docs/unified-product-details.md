# 한 번 방문으로 상품 상세 수집

랭킹 상품 상세 단계는 `enrich_product_details` 하나만 실행합니다. 상품 상세페이지를 한 번 방문하고 화면의 리뷰 요약을 먼저 읽은 뒤, 같은 페이지의 상품정보 제공고시를 펼쳐 제조업자·판매업자·전성분을 읽습니다. 수집기 자체의 추가 fetch/XHR/API 호출, 동일 상품 상세 재요청은 하지 않습니다. 페이지 자체의 일반적인 렌더링 요청은 브라우저가 수행합니다.

`scripts/product_details.js`는 현재 상품 URL/ID와 상품 헤더를 확인한 뒤 DOM에서 값을 읽습니다. 리뷰 수·평점은 상품 헤더의 `평점 4.9 리뷰 44,987건`처럼 함께 표시된 요약을 사용합니다. 추천 상품·개별 리뷰 영역은 대상이 아닙니다. 5점 범위 밖 값, 다른 상품의 페이지, 로딩 중 값은 비워 둡니다. 리뷰 0건은 실제 0으로 저장하고 평점은 null로 남깁니다.

고시 로딩/버튼 오류가 발생해도 앞에서 확인한 리뷰 수·평점은 유지합니다. 리뷰가 없어도 제조업자·성분 추출을 계속합니다. 제조업자/판매업자 분리 및 사용자 키워드 설정 규칙은 그대로 적용합니다.

통합 캐시는 `.local-browser/product-detail-cache.json`에 최대 15분간 보관합니다. 여러 카테고리에서 같은 상품을 만나면 캐시를 재사용하며, 키워드는 현재 설정으로 재매칭합니다. 이전 제조업자 캐시와 별도 리뷰 API 캐시는 통합 결과로 추정하지 않습니다. 상세페이지 조회가 끝나면 다음 상세페이지를 열기 전 2초를 기다립니다. 캐시에서 읽은 상품이나 마지막 상품 뒤에는 기다리지 않습니다. 접속 제한을 만나면 후속 상세 방문을 중단하고 짧은 중단 상태를 공유합니다. 제한을 우회하거나 같은 작업에서 재시도하지 않습니다. 상세 단계는 최대 3600초, 로컬 서비스는 3900초, 앱의 작업 대기는 3960초입니다. `COSMETICS_RANK_DETAIL_STATE_DIR`로 별도 캐시·진단 경로를 지정할 수 있어 비교 시험에서 기존 캐시를 재사용하지 않을 수 있습니다.

각 작업은 제조업자·판매업자·성분·리뷰 수·평점의 수집 개수를 `coverage`로 반환하고 관리자 수집 결과에 표시합니다. 진단과 진행 상태는 `product-detail-diagnostics.json`, `product-detail-progress.json`에 남깁니다. 확인하지 못한 값을 과거 수치로 대체하거나 0으로 추정하지 않습니다.

검증: 실제 보관한 상세 원문의 제조업자·전성분·리뷰 수 44,987·평점 4.9를 한 DOM 판독에서 확인했습니다. 고시 실패 시 리뷰 보존, 중복 상품 한 번 방문, 접근 제한 이후 후속 방문 중단, 0건/미렌더링/다른 상품 구분 테스트를 포함해 관련 JavaScript 테스트 15개 및 Python 테스트 32개, 빌드와 ESLint를 통과했습니다.

2026-11-08 실제 전체 랭킹 100개를 DB 저장 없이 시험했습니다. 100개 상세페이지 모두 정상 조회됐고 접근 제한은 없었습니다. 전체 실행은 약 18분 50초였으며 제조업자·판매업자 분리 75개, 성분 90개, 리뷰 수·평점 99개를 읽었습니다. 리뷰 1개는 페이지 요약이 렌더링되지 않았습니다. 실행 중인 로컬 서버는 재시작하면 변경된 수집 서비스를 사용합니다.

같은 날 5초 간격으로 스킨케어 랭킹 100개를 별도 빈 캐시에서 DB 저장 없이 시험했습니다. 상세페이지 100개를 실제로 조회했고 접근 제한은 없었습니다. 전체 실행은 약 10분 24초였으며 고시 원문·성분 99개, 제조업자·판매업자 분리 80개, 리뷰 수·평점 100개를 읽었습니다. 서로 다른 카테고리이므로 값의 차이를 간격의 효과로만 해석하지 않습니다.

같은 날 2초 간격으로 마스크팩 랭킹 100개를 별도 빈 캐시에서 DB 저장 없이 시험했습니다. 상세페이지 100개를 실제로 조회했고 접근 제한은 없었습니다. 전체 실행은 약 5분 33초였으며 고시 원문·성분 98개, 제조업자·판매업자 분리 78개, 리뷰 수·평점 99개를 읽었습니다. 마스크팩 1위의 리뷰 요약은 `NOT_RENDERED`였고, 68위와 99위의 성분은 비어 있었습니다. 다른 카테고리에서 나온 결과이므로 간격만의 효과로 해석하지 않습니다.

같은 날 1초 간격으로 선케어 랭킹을 별도 빈 캐시에서 DB 저장 없이 시험했습니다. 8개 상품 상세정보를 읽은 뒤 9번째 페이지에서 `ACCESS_LIMIT`가 감지돼 나머지 91개 상세 방문을 중단했습니다. 랭킹 100개 자체는 확보됐으나 상세정보는 제조업자·판매업자 분리 5개, 성분·리뷰 수·평점 8개에 그쳤습니다. 앞선 시험을 연달아 수행한 영향도 배제할 수 없어 1초만이 제한 원인이라고 단정하지 않습니다. 기본 간격은 마지막으로 100개 전체 조회에 성공한 2초로 유지합니다.
