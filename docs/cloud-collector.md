# Cloudflare 수집 운영

운영 수집기는 `cosmetics-rank-scheduler`의 `CloudCollector` Durable Object입니다. 모든 요청은 동일한 객체를 사용하여 브라우저를 하나만 실행합니다. 실행 중 수동/예약 요청은 새 브라우저를 시작하지 않습니다.

- 매일 한국시간 오전 6시 (`0 21 * * *` UTC) 실행합니다.
- 10개 카테고리의 100개 순위를 검증하고, 중복 상품 상세는 한 번만 방문합니다.
- 다음 상품 이동 전에 2초 기다립니다. 리뷰와 정보고시는 필요한 값이 나타나면 바로 읽습니다.
- Browser Run의 45초 실행 제한을 피하도록 한 실행에서 상품 1개를 처리합니다. 브라우저 세션은 계속 재사용합니다.
- 성분/제조정보는 7일간 재사용하고 리뷰/평점은 매번 새로 조회합니다. 첫 실행은 전부 조회합니다.
- 성공/실패/취소/예산 중단 시 브라우저를 닫습니다. 브라우저 종료를 확인하지 못하면 실행 잠금을 유지하고 종료만 재시도합니다.
- 정상 종료에는 즉시 닫기 API를 사용합니다. 호출 장애에 대비한 세션 유휴 만료시간은 60초입니다.
- 상세 단계의 오류는 체크포인트를 보존합니다. 같은 한국 날짜의 408/410/5xx 실패는 관리자에서 최대 2회 이어갈 수 있습니다. 이미 끝낸 상품은 다시 조회하지 않습니다.
- 브라우저를 종료한 뒤 기존 import API로 카테고리별 100개를 저장합니다. 이전 버전은 보존됩니다.
- 접속 제한을 만나면 남은 상세 조회를 중단하며 확인하지 못한 값은 비워 둡니다. CAPTCHA 우회나 자동 반복 재시도는 하지 않습니다.

관리자 수집 버튼은 서비스 바인딩으로 클라우드 수집을 요청합니다. 수집 PC의 예약 큐에는 새 작업을 넣지 않습니다. 기존 로컬 수집 기능은 별도로 사용할 수 있습니다.

## 사용량 제한

브라우저는 결제기간별 45시간, 실행별 90분을 상한으로 검사합니다. 매 호출 전 120초를 예약하고 응답의 누적 브라우저 사용량으로 정산합니다. 사용량 응답을 받지 못한 호출은 예약분을 유지합니다. 최초 장부에는 이전 테스트와 종료 오차를 위한 1시간의 예비분이 포함됩니다. 장부는 이 수집기에서 실행한 사용량만 추적합니다.

결제기간 기준일은 `BILLING_ANCHOR_DAY=8`입니다. 계정 결제일이 바뀌면 함께 변경해야 합니다. 장부는 Cloudflare 청구서나 계정 전체 사용량과 동일하지 않습니다. 45시간은 기본료 $5 + 브라우저 초과분 약 $3.15 수준으로 제한하기 위한 앱 내부 제한이며, 전체 청구액 $10을 보장하는 계정 차원의 하드캡은 아닙니다. 다른 Worker, D1, Durable Objects, 기타 서비스와 세금은 별도입니다.

요금 기준: [Browser Run 공식 가격](https://developers.cloudflare.com/browser-run/pricing/). 계정 전체 사용량은 Cloudflare 대시보드에서 확인합니다.

## 배포

두 Worker에 동일한 `COLLECTOR_CONTROL_TOKEN` secret을 설정합니다. 값을 Git에 저장하지 않습니다. 스케줄러의 직접 HTTP 제어 엔드포인트는 이 토큰이 없으면 403을 반환합니다. 관리자 API는 기존 Access/이메일/동일 출처 검사를 사용합니다.

```sh
# 테스트 배포: 예약 실행 없음
pnpm dlx wrangler deploy --config wrangler.scheduler.jsonc
# 실제 예약 신호 검증: 하루 한 번 20개를 조회하는 읽기 전용 테스트
pnpm dlx wrangler deploy --config wrangler.scheduler.jsonc --env smoke
# 운영 배포: 매일 오전 6시 예약
pnpm dlx wrangler deploy --config wrangler.scheduler.jsonc --env production
pnpm build
pnpm dlx wrangler deploy
```

관리자 상태 API는 `/api/admin/cloud-collector`, 중단 요청은 `POST /api/admin/cloud-collector/cancel`입니다. 중단은 현재 브라우저 호출이 끝난 다음 처리합니다. 상태에는 최대 20회의 요약 이력과 상세 누락 진단이 보존됩니다.
