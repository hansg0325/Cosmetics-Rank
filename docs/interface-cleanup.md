# 화면 정리와 관리자 수집·내보내기

대시보드는 1위 표를 유지하고 하단 안내, 소개와 전체 랭킹 행의 강조색을 제거했습니다. 공통 하단 출처 문구도 제거했습니다. 랭킹·상품 이력·설정에서 요청된 보조 문구를 제거하고, 점유율 분석은 수집일 선택과 집계 표 중심으로 표시합니다.

순위 변동은 하나의 비교 섹션에서 카테고리·시작일·종료일·검색을 선택합니다. 검색된 최신 랭킹 상품 중 상위 최대 30개를 자동으로 표시합니다. 기존 별도 조회 섹션, 비교 상품 선택, 축 전환, 날짜별 데이터 표와 관련 설명을 제거했습니다. 상품 범례의 강조·고정과 실제 날짜·순위 확인은 유지합니다. 날짜 라벨의 기준점을 점과 동일하게 가운데 정렬해 단일 날짜의 어긋남을 해결했습니다.

관리자의 `데이터 수집`은 전체 및 9개 카테고리의 새로운 수집 작업을 차례로 실행합니다. 진행·실패 상태와 기존 실행 중복 방지는 유지합니다. 다른 탭을 조회하거나 엑셀을 내보내는 동작은 크롤링을 실행하지 않습니다.

내보내기 탭과 랭킹의 내보내기 버튼을 제거했습니다. 관리자의 `엑셀 내보내기`는 인증된 `/api/export-rankings`에서 카테고리별 최신 활성 완료 랭킹을 읽어 10개 시트의 단일 XLSX로 저장합니다. 현재 순위 순서로 내보내고 이탈 상품은 제외합니다. 기록이 없는 카테고리는 헤더만 있는 시트를 유지합니다. 모든 카테고리가 미수집이면 안내를 표시합니다. 각 행의 수집 날짜는 기존 날짜 열로 확인할 수 있습니다.

검증: 빌드·ESLint, Vitest 95개 통과. 로컬 UI에서 요청 문구 제거, 그래프 날짜 정렬·카테고리·검색·모바일 표시, 실제 XLSX 다운로드를 확인했습니다. 다운로드한 파일은 10개 시트 각각 순위 1~100, 총 1,000행입니다. 수집 버튼은 브라우저의 요청을 모의 응답으로 대체해 10개 카테고리 호출을 검증했고 외부 크롤링은 실행하지 않았습니다.
