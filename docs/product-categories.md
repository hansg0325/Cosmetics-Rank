# 상품 대분류 수집

랭킹 카드의 `data-ref-goodscategory`에서 상품 대분류를 추출합니다. 숫자 그룹 `01`은 스킨케어·클렌징·선케어·마스크팩을 포함하므로 첫 분류명을 유지합니다. `02 > 립 메이크업 > 립케어`는 메이크업, `03 > 퍼퓸 > 향수`는 향수/디퓨저, `04 > 핸드케어 > 핸드크림`은 바디케어, `05 > 헤어 트리트먼트 > 헤어오일`은 헤어케어로 해석합니다. 구현은 `scripts/product_taxonomy.py`입니다. 빈 경로는 미수집으로 표시하고, 확인하지 못한 숫자 그룹은 기존처럼 첫 분류명을 유지합니다.

랭킹 출처인 `overall`과 상품 분류는 별개입니다. `ranking_entries.product_category_at_capture`에 수집 당시 상품 대분류를 저장합니다. 기존 기록은 NULL을 유지하며, 새로 수집한 기록부터 값이 들어갑니다. 같은 날짜 재수집은 새 버전으로 저장하고 이전 버전은 보존합니다.

랭킹·분석 표에 상품 대분류 열, 상품 검색·이력에 대분류를 표시합니다. 상품 이력의 분류는 최신 활성 완료 기록 기준입니다. 순위 출처인 더모 코스메틱·맨즈에딧으로 상품 대분류를 덮어쓰지 않습니다. 해당 랭킹에 포함된 립 메이크업 상품도 상품 대분류는 메이크업으로 표시합니다.

마이그레이션: `0003_product_category.sql`, `0004_category_replay_guard.sql`. 이후 실행 시 `bash ./start-local.sh`가 로컬 마이그레이션을 적용합니다.

검증: 전체 랭킹 100개를 다시 수집하고, 100개 모두 대분류 저장값 일치 및 상품 이력 API의 분류 일치를 확인했습니다. 결과는 `data/overall-product-categories.json`에 상품별 목록과 분류별 개수로 보관했습니다. 가격·이미지는 추가 수집하지 않습니다.
