# 랭킹 리뷰 수·평점

랭킹 표와 CSV/XLSX에 리뷰 수와 5점 만점 평점을 추가했습니다. 날짜별 스냅샷의 `review_count_at_capture`, `rating_at_capture`에 저장합니다. 기존 미수집 기록은 NULL을 유지하며 화면에 미수집으로 표시합니다. 실제 리뷰가 0개이면 0건, 평점은 평가 없음으로 표시합니다.

랭킹 카드의 숨겨진 `10점만점에 5.5점` 공통 문구를 실제 평점으로 사용하지 않습니다. 공개 상품 상세 페이지의 상품 식별 정보를 검증하고, 해당 페이지에서 사용하는 공개 추가정보 응답의 리뷰 요약만 수집합니다. 개별 리뷰, 사용자 정보, 리뷰 이미지 등은 저장하지 않습니다.

요청은 순차적으로 실행하고 상품별 확인값은 최대 15분 재사용합니다. 접근 제한이나 HTTP 429 응답이 있으면 요청을 멈추고 Retry-After에 따라 최소 60초 동안 리뷰 조회를 쉬며 기존 캐시만 사용합니다. 확인할 수 없는 상품은 미수집으로 남습니다. 따라서 일부 상품이 미수집으로 표시될 수 있습니다. 랭킹 100개 저장 자체는 리뷰 조회 실패와 별개로 유지합니다.

제조사 상세 조회 추가 후 로컬 서비스 작업 제한은 900초, 앱 대기는 960초입니다. DB 마이그레이션은 `0005_review_stats.sql`, `0006_review_replay_guard.sql`입니다. 시작 스크립트가 적용합니다. 데이터 변경 청크 재전송은 거부해 기존 스냅샷의 무결성을 유지합니다.

실제 맨즈에딧 랭킹에서 B로 시작하는 상품 ID를 확인해 A/B 상품 ID를 모두 지원하도록 맞췄습니다.

검증: TypeScript/빌드, ESLint, 기존 Vitest 83개와 리뷰 요약 테스트 3개, Python 21개 통과. 실제 3개 상품의 리뷰 요약, 0개 리뷰 처리, 잘못된 평점 척도와 다른 상품 ID 거부, DB 저장·재전송 보호, CSV/XLSX 숫자값을 확인했습니다.
