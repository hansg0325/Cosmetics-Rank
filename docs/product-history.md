# 상품 이력 표

상품 이력은 최신 수집일의 순위가 높은 순(1위부터)으로 표시합니다. 이탈 상품은 순위권 상품 뒤에 마지막 기록 순위순으로 표시하며 상품 ID로 동률을 구분합니다. 정렬과 페이지 처리는 서버에서 함께 수행해 다음 페이지에서도 순서가 이어집니다.

카테고리, 상품명·브랜드 검색, 현재 상태(전체/순위권/이탈)를 선택합니다. 날짜별 순위 열과 기간 선택은 제거했습니다. 최고·최저·평균 순위, 순위 기록일 수, 최초 진입일과 마지막 기록일은 유지합니다. 순위 통계는 해당 카테고리 전체 활성 완료 기록 기준이며 정확한 순위를 알 수 없는 이탈일과 미수집일은 제외합니다.

목록은 페이지당 20개입니다. 랭킹에서 상품을 선택하면 해당 상품만 표시하고 전체 상품 보기로 돌아갈 수 있습니다. 목록 요청은 `GET /api/product-history?category=overall&include_dates=0`을 사용합니다. 날짜별 순위를 쓰는 기존 단일 상품 이력 API와 순위 변동 탭은 유지합니다.

검증: TypeScript/프로덕션 빌드, ESLint, 분석 API 테스트 15개 통과. 100개 순위권 상품이 페이지를 넘어 1~100위 순으로 이어지고, 그 뒤에 이탈 상품이 나오며 중복이 없음을 확인했습니다. 최고·최저·평균 계산과 이탈 상품 통계 보존 테스트도 통과했습니다.
