# 성분 키워드

상품정보 제공고시의 `화장품법에 따라 기재해야 하는 모든 성분` 항목만 사용합니다. 상품명과 설명에서는 추출하지 않습니다.

대상은 PDRN, 스피큘, 글루타치온, 엑소좀, 엑토인, NAD+, 마데카소사이드, 시카, 세라마이드, 펩타이드, 아줄렌, 마이크로바이옴, 히알루론산, 피토뮤신, 레티놀, 바쿠치올, 나이아신아마이드, 비타민씨입니다.

설정 탭에서 각 규칙의 **표시할 단어**와 **포함할 단어**를 편집하고 추가·삭제할 수 있습니다. 포함할 단어는 쉼표 또는 줄바꿈으로 구분합니다. 영문 대소문자를 구분하지 않는 부분 문자열 일치로 검색하며, 하나라도 일치하면 표시할 단어를 한 번 저장합니다. 규칙 순서를 유지합니다.

PDRN 기본 규칙은 표시할 단어 `PDRN`, 포함할 단어 `PDRN, 피디알엔, 식물성 PDRN`입니다. 나머지 기본 규칙은 표시할 단어와 같은 단어를 검색합니다. 별칭은 사용자가 포함할 단어로 등록한 경우에만 적용합니다. 예를 들어 시카 규칙에 병풀추출물을 추가하면 해당 원문을 시카로 표시할 수 있습니다.

규칙은 인증된 `/api/settings/keywords` GET/POST로 D1 `app_settings`에 저장합니다. `0011_keyword_settings.sql` 마이그레이션이 필요합니다. 설정은 다음 크롤링 작업에 고정해 전달되므로 수집 중 설정을 바꿔도 진행 중인 작업에는 영향을 주지 않습니다. 상세 성분 캐시에도 새로운 규칙으로 다시 매칭합니다. 기존 이력은 변경하지 않습니다. 표시할 단어 중복, 빈 검색 목록, 쉼표를 포함하는 단일 단어 등은 거부합니다. 최대 100개 규칙, 규칙당 30개 포함 단어를 허용합니다.

성분 항목을 확인하지 못했거나 상세페이지 참조만 있으면 미수집(null)으로 남깁니다. 성분 원문은 있지만 일치하는 키워드가 없으면 빈 목록으로 저장합니다. 두 경우 모두 표에는 빈칸을 표시하고 도움말로 구분합니다. 추출값은 랭킹 표와 CSV/XLSX의 키워드 열에 표시합니다.

기존 제조업자 수집과 같은 페이지에서 성분 항목을 읽고 원문을 로컬 캐시에 최대 24시간 보관합니다. 성분 정보가 없는 기존 캐시는 다음 수집 때 다시 확인합니다. 접속 제한이 나타나면 상세 조회를 중단합니다. DB 적용에는 0009, 0010 마이그레이션이 필요합니다.

이번 검증은 추가 외부 조회 없이 이미 보관한 에스트라 상품 A000001002386의 실제 성분 원문을 사용했습니다. 세라마이드와 나이아신아마이드가 추출되어 전체 랭킹의 새 버전에 저장되었습니다. 나머지 99개 상품의 성분 키워드는 아직 미수집 상태이며 다른 카테고리는 변경하지 않았습니다.
