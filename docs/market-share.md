# 점유율 분석

점유율 분석 탭은 선택한 수집일의 활성 COMPLETE 전체 랭킹(`overall`)만 집계합니다. 다른 카테고리 랭킹이나 직전 랭킹의 이탈 상품은 합산하지 않습니다.

- 카테고리명: 수집 당시 상품 대분류. 없는 경우 미분류로 집계합니다.
- 상품 수: 해당 카테고리의 전체 랭킹 진입 상품 수. 비율의 분모는 전체 랭킹 상품 수입니다.
- 최대 점유 브랜드: 해당 카테고리 내 최다 상품 브랜드. 분모는 해당 카테고리 상품 수이며 공동 1위는 모두 표시합니다. 브랜드 누락을 임의 브랜드로 취급하지 않습니다.
- 키워드: 해당 카테고리에서 수집된 키워드와 키워드별 상품 수. 한 상품의 같은 키워드는 한 번만 셉니다. 성분 확인 상품 수를 함께 표시합니다. 미수집과 확인했지만 일치 키워드가 없는 상태를 구분합니다.

카테고리는 상품 수 내림차순으로 표시합니다. 수집일 선택으로 과거 완료 기록도 조회할 수 있습니다. 데이터가 없거나 아직 수집 중인 스냅샷은 집계하지 않습니다.

API는 인증된 `GET /api/market-share?date=YYYY-MM-DD`입니다. 별도 DB 마이그레이션이나 추가 크롤링은 필요하지 않습니다.

검증: 집계 단위 테스트 2개, 관련 D1/API 테스트 17개 통과. 실제 저장된 전체 랭킹 100개를 11개 카테고리로 집계하고 상품 수·비율 합계, 키워드 표시 및 모바일 가로 넘침을 확인했습니다.
